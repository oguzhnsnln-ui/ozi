OĞUZHAN ŞANALAN — V32

Bu sürüm, önceki PHP paneli tamamen kaldırılmış, siteyle bütünleşik ve PHP'sizdir.

AÇMA:
index.html dosyasını aç. Site normal şekilde gelir.
Sol üstteki OŞ logosuna tıklayınca admin giriş paneli açılır.

ADMİN:
Kullanıcı: admin
Şifre: OSAdmin!2026

ADMİNDE:
- Ürün ekle / düzenle / sil
- Telefon / bilgisayar seç
- Ürün fotoğrafı yükle ve önizle
- Fiyat, kısa bilgi ve özellikleri kolayca gir
- Profil fotoğrafını değiştir
- Kapak fotoğrafını değiştir
- Galeriye fotoğraf ekle / sil
- Site müziğini değiştir, dinle, aç/kapat
- Yedek indir

TEKNİK:
- PHP yoktur.
- Admin paneli index.html içindedir.
- CSS tasarımı admin.css içindedir.
- Admin işlemleri admin.js içindedir.
- Veriler IndexedDB'de bu tarayıcıda saklanır.
- Bu nedenle yapılan değişiklikler aynı tarayıcıdaki site ziyaretçisinde görünür; başka cihazlara otomatik yayınlanmaz.
- Gerçek çok kullanıcılı internet yayını / sunucu veritabanı için bir backend gerekir.

NOT: Tarayıcılar kullanıcı tıklaması olmadan sesli otomatik oynatmayı engelleyebilir. Müzik dosyası sitede mevcut ve ilk kullanıcı etkileşiminde başlatılmaya çalışılır.
